# 参考图分析与图片反推指南

本文档详述 Mode B（参考图分析）与 Mode C（图片反推）的分析维度、输出格式与处理原则。

---

## Mode B：参考图分析维度

从图片中分析以下维度。

### 主体

人物 / 产品 / 动物 / 建筑 / 道具 / 环境

### 人物

性别表现、年龄区间、外貌特征、发型、服装、姿态、动作、表情。

不得凭图片过度推断不可确定的人物身份、真实背景或敏感属性。

### 场景

室内/室外、城市/自然、前景、中景、背景、环境元素

### 构图

横向/纵向、景别、主体位置、对称/非对称、留白、视觉中心、前中后景关系

### 摄影

机位、拍摄角度、景深、焦段倾向、虚化程度、运动感

### 光线

主光方向、光线强弱、硬光/柔光、顺光/侧光/逆光、自然光/人造光、高光与阴影

### 色彩

主色、辅助色、冷暖关系、饱和度、明度、色彩氛围

### 材质

金属、玻璃、布料、皮革、木材、塑料、皮肤、水面等

### 风格

写实摄影、商业摄影、时尚摄影、电影感、杂志感、极简、复古、赛博朋克、插画、3D 渲染等


---

## Mode C：图片反推输出格式

```
【图片反推】

核心主体：...
场景：...
构图：...
摄影：...
光线：...
色彩：...
风格：...
关键细节：...

【反推 Prompt】
...

【不确定信息】
...
```

必须区分：图片明确呈现的信息 vs 模型根据视觉规律推测的信息。

推测性信息使用标记词：`推测：` / `可能：` / `倾向于：` / `无法确定：`

反推时优先还原：1.主体 2.主体动作 3.场景 4.构图 5.摄影方式 6.光线 7.色彩 8.材质 9.风格 10.氛围 11.关键视觉细节。

对于无法从图片确定的信息，禁止假装确定。

---

## 参考图处理原则

用户提供"参考图 + 新需求"时区分：

### 必须继承

用户明确要求保留的：构图、风格、色调、镜头、场景、人物姿态。

### 可以修改

用户明确要求变化的：人物、产品、服装、场景、色彩、道具。

不得因参考图存在就默认所有元素全部复制。

---

## 图片反推的限制

反推不是"读取原始 Prompt"。

必须明确：反推得到的是基于视觉结果的近似 Prompt，而不是原始生成指令。

因此：
- 不声称知道原始 Prompt
- 不声称知道具体模型
- 不声称知道具体参数
- 不确定的信息必须标记为推测
