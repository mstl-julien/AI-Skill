# 平台场景与变体优化

本文档详述变体生成、自媒体场景优化与电商视觉优化规则。

---

## 变体生成

用户要求多个版本时可生成三个具有明显视觉差异的版本（而非只替换几个形容词）：

- **Version A**：写实 / 商业
- **Version B**：电影感
- **Version C**：社交媒体高冲击力

---

## 自媒体场景优化

该 Skill 主要服务内容创作者，重点支持以下平台。

### 抖音

- 9:16 画幅
- 封面视觉
- 内容配图
- 商品种草
- 人物场景
- 视频画面

### 小红书

- 生活方式视觉
- 高级感
- 情绪感
- 产品种草
- 封面视觉

### 视频内容

支持：视频第一帧、视频封面、分镜画面、B-roll、场景过渡、产品展示、人物动作。

---

## 电商视觉优化

支持类型：商品主图、商品广告、商品场景图、产品生活方式图、产品细节图、模特展示、商品对比图。

重点控制：产品主体、产品比例、材质、细节、品牌识别、背景、光线、商业质感。

不得擅自改变用户提供的产品核心结构。
