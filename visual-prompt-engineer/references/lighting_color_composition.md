# 光影、色彩与构图进阶语法

> 来源：90 提供深度授课资料，2026-09-28 沉淀。
> 定位：三段论（主体+环境+媒介）中**媒介段的进阶词汇库**，同时服务于环境段的光源场景设计。结构层方法见 `subject_environment_medium_guide.md`。
> 标注【已验证】的条目在本工作空间的实测中生效过（斗笠剑客三风格实验、青花瓷 Prompt）。

---

## 一、光影语法：光是画面的第一叙事者

### 1. 光质（硬 / 软）

由**光源相对尺寸与距离**决定：

- **硬光**（直射阳光、裸灯）→ 阴影边缘锐利、高光集中、戏剧性强
- **软光**（阴天、柔光箱）→ 阴影过渡绵软、材质呈现均匀【已验证：青花瓷 Prompt 的"阴天漫射天光"即软光】

### 2. 光向与经典布光范式（光向本身携带情绪语义）

| 布光 | 定义 | 情绪/用途 |
|---|---|---|
| **伦勃朗光** | 侧上方约 45° 主光，暗侧脸颊形成倒三角光斑 | 人像戏剧感首选 |
| **分割光（侧光）** | 明暗各半 | 对立、抉择类叙事 |
| **边缘光（轮廓光）** | 自主体后侧方勾勒轮廓 | 主体从暗背景中剥离，"强冲突光影"的分离工具 |
| **逆光** | 光源在主体后方 | 剪影或透射质感（叶片、织物、发丝） |
| **顶光** | 光源自上方 | 审判感或神圣感 |
| **底光** | 光源自下方 | 不安与威胁感 |

**⚠️ 光向自洽法则**：布光范式携带**隐含几何光向**（伦勃朗＝侧上方约 45°），当它与显式光向指令物理互斥（如同时写"头顶天窗"＝顶光），模型折衷后范式特征必然泛化（三角光斑消失）——实测偏差：老铸剑师案例，伦勃朗光斑泛化。修正：令光源几何与范式自洽——"天窗**自左上方约 45° 倾角**投下"。同族冲突：姿势冲突、清晰度×虚焦。

### 3. 光效现象词

**分类学注记**：现象词仅指物理光学现象（丁达尔/焦散/gobo/眩光）；**布光范式（伦勃朗/分割/边缘光）属"光向范式"**——范式携带隐含光向，现象词需要介质，二者控制逻辑不同，拆解与归档时须分开归类，不可混标。

- **丁达尔效应 / 体积光**：光束可见，需介质（雾、尘、烟）【已验证：赛博图"雨丝在光束中清晰可见"】
- **焦散**：水面/玻璃折射的光纹
- **光斑投影（gobo）**：窗格影、叶影
- **眩光与辉光**

### 4. 阴影色彩（脱离"AI 感"的关键一步）

阴影不是黑色——**阴影的色彩由环境光决定**：

- 暖主光下阴影偏冷蓝
- 霓虹场景中阴影染环境色
- 写出 shadow color 是进阶标志

**负补光**（黑旗吸光加深暗部）的自然语言写法："暗部不受环境光污染，沉入深影"。

## 二、色彩语法

### 1. 色温对立（冷暖对置即冲突）

- 橙 / 青（电影主流）
- 琥珀 / 冷蓝
- 烛金 / 月蓝
- 品红 / 青【已验证：赛博图双色霓虹】

### 2. 配色结构与饱和度层级

- **配色结构**：互补色对抗、邻近色和谐、单点重彩【已验证：国风"全画仅以朱红剑穗作点睛重彩"】
- **饱和度层级**：主体饱和度高于环境 → 主体前突；反之 → 主体融入叙事

### 3. 环境染色 / 反弹光

主体暗侧应染环境色（如雪地反光使下颌偏冷）。写作 **"反弹光"** 或 **"环境染色"** 可显著提升物理可信度。

## 三、镜头与构图语法

### 1. 焦段语义

| 焦段 | 语义 |
|---|---|
| 24mm | 透视夸张（前景放大、空间拉伸）→ 压迫与张力 |
| 35mm | 叙事焦段（环境与人均衡） |
| 50mm | 中性 |
| 85mm | 人像压缩（背景贴近、面部比例真实） |
| 200mm | 空间压缩（层叠感、孤立感） |

### 2. 光圈与焦平面

- f/1.8 级浅景深 → 隔离主体；f/8 级深景深 → 交代全局
- **焦平面位置即视觉引导指令**【已验证："焦点落在最高的花瓶上"】

**f 值弱约束法则**：扩散模型不做光圈物理仿真，f/2.0 仅是风格暗示——**定性焦外描述才是强约束**。补丁三件套：①焦外状态（"背景熔入焦外"）②背景元素形态降级（"悬挂工具仅余模糊轮廓"）③焦平面锐利对象显式声明（"唯焦平面上的右眼与握锤之手锐利"）。

### 3. 机位情绪

- 俯拍 → 脆弱 / 全局 / 宿命感
- 仰拍 → 英雄 / 压迫 / 崇高【已验证：赛博图低角度仰视】
- 平视 → 客观 / 平等
- 倾斜机位 → 不安 / 失衡

### 4. 构图法则与景别层级

- 法则：三分法、引导线、框中框、负空间【已验证："左侧留出充足负空间"】、前景遮挡
- **景别层级**：特写 → 情绪；中景 → 关系；全景 → 处境

**景别 × 环境具名权衡**：环境元素（铁砧、炭火、工作台）具名入词会把取景框外拉——声明"中特写"实际执行成中景（实测偏差：老铸剑师成图腰上构图）。锁紧景别两法：①削减环境具名元素数量；②显式排除＋局部暗示（"画幅截取至胸部以上，铁砧与炭火仅以画框下缘局部暗示"）。

## 四、"强戏剧冲突光影"合成公式

**单一硬光源 ＋ 高光比（明暗对照法/暗色调主义）＋ 深色阴影 ＋ 边缘光分离 ＋ 机位强化**

参考示例（句式参照）：

> 老铸剑师的面部被头顶天窗投下的单一硬光切割，亮侧皮肤纹理毕现，暗侧沉入深影，仅颧骨处留一枚伦勃朗三角光斑；炉火的橙红反弹光自下方舔舐其下颌，与天窗冷光形成色温对抗；一道边缘光勾勒其肩背轮廓，使其从漆黑的作坊背景中剥离。35mm 焦段，f/2.0，低角度仰视中特写，明暗对照法，电影级调色。

## 五、提示词句式公式

- **光影句** ＝ 光源性质 ＋ 方向 ＋ 色温 ＋ 光质 ＋ 阴影行为（长度/边缘/**色彩**）＋ 现象词
- **色彩句** ＝ 色温对立或配色结构 ＋ 饱和度层级 ＋ 环境染色
- **镜头句** ＝ 焦段 ＋ 光圈/焦平面 ＋ 机位 ＋ 景别

三句组装进三段论的"媒介段"（光影句/色彩句通常接在主体材质-光影绑定之后，镜头句与画质词收尾）。
