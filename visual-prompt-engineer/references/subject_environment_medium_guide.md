# 主体 + 环境 + 媒介：三段论深度方法论

> 来源：90 提供的千问（通义万相）提示词方法论资料，2026-09-28 沉淀。
> 核心认知：千问模型具备强大的自然语言理解能力，它不是在做"关键词匹配"，而是在进行**"场景重建"**。因此提示词必须像电影导演的剧本一样，具备严密的**物理逻辑**与**视觉层次**。
>
> 标准结构：**主体（Subject）+ 环境（Environment）+ 媒介（Medium）**。这是本 Skill 生成 Prompt 时的宏观组织方式（90 确认的首选结构）。

---

## 一、主体 (Subject)：从"概念"到"实体"的具象化

主体是画面的视觉中心。描述主体不能停留在名词层面，必须赋予其**物理属性**。

### 1. 外观与细节 (Appearance & Details)

- **基础设定**：类别、性别、年龄、体型。
- **服饰与纹理**：不要只写"穿着外套"，要写"穿着做旧的棕色粗花呢大衣，边缘有磨损痕迹"。细节特征（如面部的雀斑、衣服上的褶皱走向）能大幅提升画面的真实感。

### 2. 动作与物理交互 (Action & Physical Interaction)

- **动态张力**：描述动作时，要想象重力和受力点。不要只写"拿着杯子"，要写"手指紧紧握住陶瓷杯的把手，指关节因用力而微微泛白"。
- **接触关系**：明确主体与周围物体的接触点，避免"悬浮感"。
- **手别锁定**：写手部动作时，左/右手归属是肢体类语义冲突的高发槽位（易出现双手各持一物、镜像错乱）。要么明确手别（"左手扶笠檐、右手扣刀柄"），要么回避手别表述——不要留这个槽位给先验。

### 3. 材质与光学属性 (Material & Optical Properties)

材质词的本质：**告诉模型该物体的表面如何与光线交互**。

- **陶瓷/玻璃类**：
  - 上釉/抛光 → 强烈的镜面反射和高光斑点。例："光滑的青瓷表面反射着窗外的天光"
  - 哑光/粗陶 → 漫反射，表面有微小颗粒感。例："粗糙的未上釉陶土罐"
- **金属类**：
  - 抛光金属 → 如镜面般映射周围环境，高光锐利
  - 拉丝金属 → 具有方向性的细微纹理，反光柔和
  - 氧化/生锈金属 → 表面粗糙，色彩斑驳，漫反射为主

**💡 核心法则：材质词必须与光源词绑定。** 没有光，材质就无法显现。"黄铜材质"是相对单薄的描述；"在侧逆光下泛着温暖光泽的拉丝黄铜"才是具备视觉引导力的有效描述。

**💡 哑光材质的绑法：绑微阴影，不绑高光。** 哑光材质无高光可写，其质感靠**掠射光（raking light）下的微阴影**显现："侧向天光掠过布面，织纹起伏投下细密微阴影"。扩散模型偏爱渲染镜面高光（高频特征），最容易抹平哑光织纹（低频微对比）——哑光材质若不绑光，渲染会退化成"一块普通布"。

**⚠️ 冲突禁例**："织物纹理清晰"与"前景虚焦"不可同时出现。虚焦材质应改写**虚焦后的视觉形态**（"织纹虚化作细腻绒感"），并删去清晰度描述。另注意对比设计的不对称风险：画面依赖"哑光×镜面"材质对比时，镜面侧要写足光效，哑光侧也必须补掠射光微阴影，否则对比系统单边塌陷。

## 二、环境 (Environment)：构建空间纵深与叙事氛围

环境不仅是主体的背景，更是**烘托情绪、提供光源的舞台**。

### 1. 时间与光影 (Time & Lighting)

时间不仅决定明暗，更决定**色温与阴影形态**：

| 时间 | 视觉特征 |
|---|---|
| 清晨 | 冷蓝调、柔和长影 |
| 正午 | 硬光、短影、高对比度 |
| 黄昏 | 暖金调、极长的阴影、丁达尔效应易发 |
| 夜晚 | 人造光源主导、高反差 |

**光影质感**：明确光是"硬光"（如直射阳光，边缘锐利）还是"软光"（如阴天或透过窗帘的光，边缘模糊）。

### 2. 地点与空间纵深 (Location & Spatial Depth)

采用**"宏观 → 中观 → 微观"**的推演逻辑：

- 宏观：赛博朋克城市的霓虹暗巷
- 中观：一家冒着热气的街角拉面摊
- 微观：桌面上放着的一碗撒着葱花的拉面

**环境叙事**：环境应暗示主体的状态。例如，杂乱的书桌暗示主人的忙碌或随性。

### 3. 天气与空气透视 (Weather & Atmospheric Perspective)

除了基础的晴雨雪，要利用天气制造**"空气感"**：

- "雨后的湿润地面反射着霓虹灯"
- "晨雾使得远处的树林色彩变淡（空气透视）"
- "空气中漂浮的灰尘在光束中飞舞"

## 三、媒介 (Medium)：定义画面的"渲染引擎"与"镜头"

媒介决定图像最终的视觉呈现形式，相当于给模型指定一个**"虚拟相机"**或**"渲染软件"**。对应 Prompt Schema 的 [Camera] + [Style] + [Quality] 合并层。

### 1. 艺术媒介 / 渲染器

- **摄影类**：35mm 胶片摄影、宝丽来拍立得、数码单反
- **3D/CG 类**：Octane Render（强调光影与材质真实感）、Unreal Engine 5（强调宏大场景与全局光照）
- **绘画类**：水彩、油画、厚涂、新海诚动画风格

### 1.5 风格词的位置策略：渲染型 vs 结构型（实战沉淀 2026-09-28）

同主体多风格实验（斗笠剑客 × 国风/赛博/盲盒）验证的分层埋放规则：

- **渲染型风格**（只改笔触/光影/色调/媒介，不改主体结构：国风、赛博朋克、油画、摄影写实）→ **风格词集中放媒介段（句尾高注意力区）**，主体段保持纯物理描述，主体细节不被风格词污染，还原度最高。环境段用"风格化素材选择"隐性承载风格（国风配竹林古道、赛博配霓虹雨巷），不在环境段堆风格词。
- **结构型风格**（改变比例/形态/材质逻辑：Q版、盲盒、卡通、极简几何化）→ **风格词必须前置到主体段句首**（"Q版盲盒手办风格的年轻剑客"），比例与材质改写直接写进主体描述。放媒介段来不及——模型已按正常比例画完主体，事后风格化会失败。
- **色调/光影签名**跟在风格词后立即出现（如"赛博朋克概念艺术"后紧跟"品红与青色双色霓虹高反差"），形成风格-色彩强绑定。
- **副作用预警｜指令过执行**：反射类动词（映射/反射）在**高反差风格下会被模型升级为自发光**（"剑刃缝隙映射霓虹"→发光能量刃）。补丁写法：**追加保留子句**——"剑刃金属映射蓝紫色霓虹，同时保留金属本体的冷硬质感"。需要材质被光"映"而非"透"时，写"表面映出 X 色反光"并强调材质本体。

### 1.6 风格对细节还原度的影响（同主体三风格实验复盘 2026-09-28）

斗笠剑客 × 国风/赛博/盲盒实测结论：**细节还原度：工笔国风 > 赛博朋克 > 3D盲盒**。

两种扭曲机制：

- **光效挤占（渲染型风格内的隐性扭曲）**：强光源+高反差风格（霓虹/发光/全息）占用模型注意力预算——"映射"被执行成"发光"（材质变光源），低明度小元素（剑穗）在高对比环境信噪比过低被淹没。危险点：不在风格定义内，属执行副作用，交付前不可预期。
- **几何重构连锁变形（结构型风格的定义内扭曲）**：比例改写（Q版/盲盒）是全局几何变换，依比例存在的细节（武器尺寸、衣褶、年龄感）连锁变形。非执行失败，是风格代价。

**双框架 reporting（商业验收必备）**：

- **源主体保真度**：成图与源主体（原始物理描述）的吻合度——此框架下排序：国风 > 赛博 > 盲盒
- **规格保真度**：成图与预编码规格的吻合度——此框架下盲盒最高（浅刻线、红球逐条兑现）
- 同一批图在两框架下排序可完全不同。验收前先声明采用哪个框架，"授权变形"在源保真框架是失分项、在规格保真框架是得分项。

实操推论：

1. 要细节还原 → 渲染型风格；工笔类"精细描摹"语言与主体细节描写不竞争，保真最高
2. 必须用结构型风格 → Prompt 内主动声明简化策略（哪些细节"简化保留"、哪些"删除"），主动授权优于被动丢失
3. 交付前隐蔽扭曲排查：材质是否被光效吞并（映射→发光）、低明度小元素是否存活

### 2. 镜头语言 (Camera Language)

- **焦距**：
  - 广角镜头（如 24mm）→ 强烈的透视畸变和宽广视野
  - 长焦镜头（如 85mm）→ 空间压缩感和背景虚化
- **景别**：
  - 极特写 → 强调局部纹理
  - 中景 → 展示动作与环境关系
  - 远景 → 展示宏大场景
- **视角**：
  - 平视 → 客观
  - 俯拍 → 上帝视角，展现空间布局
  - 仰拍 → 凸显主体的高大与压迫感

### 3. 画质修饰词 (Quality Boosters)（千问特化）

千问理解自然语言，但在句末补充 **"8K 分辨率、极高细节、杰作、光线追踪"** 等词汇，能有效提升模型在解码时对高频细节（如毛发、纹理）的注意力权重。

## 四、模型解析机制：注意力权重与语义对齐

> 来源：千问对实战 Prompt（青花瓷花瓶案例）的批复反馈，2026-09-28 沉淀。摄影美学之外，还需从 AI 扩散模型的底层注意力机制出发微调 Prompt。

### 1. 注意力权重衰减 (Attention Decay)

- **现象**：模型处理超长文本时，对**句首和句尾**的注意力权重较高，**中间部分容易衰减**。
- **推论**：主体放最前是正确的；但若把核心光影条件（色温、氛围光）埋在"媒介"段最后，模型渲染材质细节时可能用不上这些光效。
- **规则**：**光影条件前移，紧跟主体材质描述之后，形成"材质-光影"强绑定**；画质修饰词放句尾收束（句尾同样是高注意力区）。
- **冗余稀释**：拼接/修订 Prompt 时必须**去重**——重复短语是冗余 token，会稀释同段其他描述的注意力权重（如开篇句与原句都写"笠檐雨水成串滴落"）。

### 2. 物理术语的语义转化

- **现象**："约6500K"是精确的人类摄影术语，但模型训练时更常与"清晨阴天冷蓝调""冷色温自然光"等**视觉描述词**对齐。
- **规则**：**用视觉语言替换物理参数**，降低解析偏差。保留直觉化描述（"柔和长条状高光"），去掉仪表化数字（6500K）。

### 3. 物理深度的辅助视觉词

- **现象**："钴蓝纹样如悬浮在透明釉层之下"意境极佳，但模型本质生成 2D 像素，很难凭空理解"釉层厚度"带来的 3D 折射。
- **规则**：**为物理深度补辅助视觉词**，主动"喂"给模型深度感知线索。例："釉面具有明显的厚度感与通透感"、"纹样具有微弱的立体深度"。

### 已验证的有效写法（千问批复确认的优点）

- 材质×光源因果闭环："外罩玻璃质透明釉" ↔ "弧肩处柔和长条状高光"——模型可据此准确计算高光形状与柔度
- 景深与视觉引导的精准调度："左侧留出充足负空间"、"前景虚焦"、"焦点落在最高的花瓶上"
- 环境叙事与情绪渲染："昨夜刚停雨的清晨" + "水汽薄雾" → "如被雨洗净般的沉静"

## 五、约束强度与漂移控制（跨种子可复现性）

> 来源：千问对多风格对比实验的二次批复，2026-09-28 沉淀。

### 1. 约束强度三级（漂移量随等级递减而递增）

1. **量化/关系化描述**（最强）：头身比 1:1.2、单点重彩、数量关系——锁定最牢
2. **特征化描述**（中）：湿笠映霓虹、掠射微阴影——靠独特特征锚定
3. **具名描述**（最弱）：石板路、底座——只给类别不给规格，漂移最大

**推论**：需要锁定的元素必须升级到量化/关系化层级；仅具名的元素默认接受漂移。

### 2. 两类范式的跨种子稳定性

- **范式 A（结构型：句首锚点＋形态预编码）**：宏观形态跨种子最稳定，漂移仅出现在未编码的微特征（如眉部表情）→ **预编码规格即验收标准，未编码处即漂移处**
- **范式 B（渲染型：段尾锚点＋分布式线索）**：风格激活完整且跨种子稳定，漂移集中于**中景布局层**——该层仅获"远/中/近"纵深指令而未获逐元素定形 → **布局层若需锁定，须逐元素定形**

### 3. 表情显式化

表情属角色设定组成部分 → 显式写入（如"眉梢微蹙，神情坚毅"）；刻意留白 → 复盘中声明。避免留白漂移被误判为执行失败。

### 4. 可审计性要求

- 记录**种子与采样参数**，复盘才能区分"提示词效应"与"种子效应"（工具不暴露种子时，以文件名时间戳＋Prompt 原文归档替代）
- **画幅比例写入 Prompt 末尾**（如"2:3 竖幅比例"），与生成侧参数双保险，保证归档一致性
- **图词对齐提交**：Prompt 与成图一一对应归档

### 5. 槽位理论与自由度三维（资产级结论，2026-09-28）

**术语界定**：

- **提示词驱动的强锁**：Prompt 显式写入的量化/关系化/特征化约束（单点重彩、双色色域、头身比、浅刻线）——不要与"先验驱动元素"混淆
- **先验驱动元素**：Prompt **未写**、由模型先验补全的内容（留白的位置与形状、苔藓密度、招牌文字内容、背景行人、腮红、底座木纹、眉形）

**槽位理论（核心资产）**：自由度不存在于"未指定的层"，而存在于**"已指定类别内的未指定槽位"**——"汉字霓虹"锁类别留**文字槽**，"圆形底座"锁形状留**材质槽**，"大面积留白"锁数量留**位置槽**。先验补全永远发生在槽位内。控制一个元素 ≠ 控制它的全部属性，只控制了写死的那些槽。

**自由度三维报告**（替代单维"自由度大小"表述）：

- **加法自由度**（画面能被添加什么）：国风最小——水墨语法约束了添加物
- **布局自由度**（元素在空间中如何排布）：盲盒最小——"极简摄影棚"清零了布局槽位
- **微特征自由度**（未编码的微细节）：盲盒最小——形态预编码后仅剩眉形等微槽

同主体跨种子漂移实证：盲盒漂移仅限眉形等微特征；国风石阶布局、赛博地面涟漪均漂移（布局槽位开放所致）。

**关联**：先验覆写（强先验场景抢占弱元素槽位）是槽位机制的反面应用，多元素画面的失效诊断与绑定控制见 `element_binding_control.md`。

## 应用检查清单

生成三段论 Prompt 时自检：

1. 主体是否从名词升级为"具备物理属性的实体"？（细节/动作受力/接触关系）
2. 每个材质词是否绑定了光源？（高光材质绑高光形状；**哑光材质绑掠射光微阴影**）
3. **是否存在清晰度与虚焦的冲突描述？（虚焦材质写虚焦后形态）**
4. **光影条件是否紧跟材质描述、未被埋进中段？**
5. **物理参数是否已转化为视觉描述词？（无 6500K 类仪表数字）**
6. **3D 物理深度是否补了辅助视觉词？（厚度感/通透感/立体深度）**
7. 环境是否有"宏观→中观→微观"的纵深层次？
8. 时间是否明确了色温与阴影形态？
9. 天气是否制造了"空气感"（空气透视/水汽/灰尘）？
10. 媒介是否选定了明确的艺术媒介 + 焦距 + 景别 + 视角？
11. **画质修饰词是否收在句尾高注意力区？**
12. **表情是否显式写入，或已在复盘中声明刻意留白？**
13. **需要锁定的元素是否用了量化/关系化描述，而非仅具名？（约束三级）**
14. **归档是否含种子/采样参数（或时间戳）与画幅比例声明？**
15. **拼接/修订 Prompt 时是否已去重？（冗余 token 稀释权重）**
