# 项目级创作工作流（封面 / 系列图）

> 来源：90 提供深度授课资料，2026-09-28 沉淀。
> 定位：**单图知识的总装线**。三段论（结构）、光影色彩语法（渲染）、绑定控制（逻辑）都是单图层技能，本文件回答"一张功能性图像 / 一组图**为何而画、如何流程化生产**"。
> 层级调用关系：阶段 3 架构中的 [主体层][场景层]＝三段论（`subject_environment_medium_guide.md`）；[光色层][镜头构图层]＝三句式公式（`lighting_color_composition.md`）；多元素＝绑定句法（`element_binding_control.md`）；阶段 4＝验证协议（`element_binding_control.md` 第六节）。

## 一、单图提示词 vs 项目级提示词

- 单图提示词回答"**画什么**"；项目级提示词回答"**为何而画**"。
- 封面是功能性图像，须同时完成**三重任务**：
  - **叙事**：类型信号（一眼看出题材）
  - **审美**：视觉锚点（留住视线）
  - **工程**：标题负空间、安全区（文字排印可用）
- 因此项目级引入**需求拆解层**，置于提示词之前。

---

## 二、五阶段工作流

### 阶段 0 · Brief 拆解

主题词 → 关键词簇 → 情绪基调。

示例："未来东方城市" →
- {东方：飞檐 / 斗拱 / 牌坊 / 灯笼 / 汉字 signage / 朱砂与墨色}
- × {未来：巨构尺度 / 全息 / 霓虹 / 大气透视 / 冷基色}
- → 情绪：崇高 ＋ 乡愁

### 阶段 1 · 概念发散与收敛

产出 **A/B/C 三个一句话视觉概念**，择一并陈述理由。

收敛依据：叙事焦点清晰度、类型信号强度、可渲染性。

### 阶段 2 · 文字构图草图

- 前 / 中 / 远景**块面**
- **光源图**：主光 / 反弹光 / 边缘光位置
- **色彩脚本**：基色 / 对抗色 / 单点重彩
- **标题负空间位置**

### 阶段 3 · 项目级提示词撰写

架构 ＝
**[媒介与类型锚点] ＋ [主体层] ＋ [场景层] ＋ [光色层] ＋ [镜头构图层] ＋ [封面功能层（标题负空间、低细节区声明）] ＋ [画质收束]**

与单图 Schema 的差异：新增媒介锚点（类型信号）与封面功能层（工程任务）；其余层级复用单图知识。

**Taxonomy 映射注记**：单图三段论的"媒介段"＝项目级七层的 [光色层]＋[镜头构图层]＋[画质收束]——两套命名是不同粒度的架构（单图三段 / 项目七层），归档时按所在架构对齐命名，不强行统一。

### 阶段 4 · 多种子验证与局部调整

- **n=4 次生成**，按五类 taxonomy（`element_binding_control.md`）记录失效
- 成功率 ＝ 成功数 / 4，**达标线 ≥3/4（75% ＞ 70%）**
- **成功定义** ＝ 五类无致命失效 **且** 核心约束（主体 / 动作 / 标题负空间）全部落地
- 平台能力适配：ImageGen 无独立负面字段、局部重绘假定不可用 → 以**提示词级迭代替代 inpainting**，并以**版本变更记录留痕**（v1→v2 改了什么、为何改）

**双轨测量法（验收裁决规范，2026-09-28 封面项目确立）**：

- **层内约束**：提示词可控的约束（语义失效五类、主体、动作、光色、镜头、构图）——计入提示词能力指标，达标线 ≥70%
- **层外约束**：与模型构图先验对抗的约束（如"巨构高密度先验 vs 标题负空间"）——属**模型能力边界**，不计入提示词能力指标；以受控迭代证伪（单变量变更→无改善→排除"指令缺失"假设）后，转入工程兜底（排版遮挡 / inpainting / 分阶段生成）
- 成功率报告必须**双轨分开**：混报等于用模型天花板考核提示词笔力
- 实测案例：未来东方城市封面——层内 4/4=100%（超额达标），层外 25-50%（边界），裁决合格

### 阶段 5 · 定稿与归档

终版提示词版本号、变更记录、种子/时间戳、**弃稿理由清单**（弃稿也归档——为何不用与为何用同等重要）。

## 三、封面专属知识

### 1. 标题负空间

于画面上部或侧部声明**低细节区**："画面上三分之一为雾霭与天空构成的低细节负空间，供标题排印"——防止模型在该区堆砌细节。

**验收标准修正（Typography Masking，2026-09-28）**：负空间的验收标准是**文字可读性**，而非"零细节"——只要该区域**无破坏文字可读性的硬边缘与高对比度细节**（色调统一、低对比的雾霭/暗调夜空）即算达标。双口径报告：严格口径（整区零细节）与排版口径（存在可排印的低对比连续区）需分开统计。

**商业工业解法（生成模糊基底 ＋ 后期排版遮挡）**：

- **生图阶段**：只需确保负空间区域色调统一、对比度较低，微小瑕疵由后期文字色块与阴影自然掩盖
- **排版阶段**：设计师将标题、作者名直接压在低对比区域上
- **进阶手段**（平台支持时）：局部重绘（Inpainting）框选上部二次生成"纯净夜空"；或 ControlNet（深度图/线稿）强制锁定构图
- 本工作空间工具链（ImageGen）无 inpainting/ControlNet → 提示词级迭代对此失效模式（构图先验对抗）效率低，实测 v1→v2 未提升负空间成功率——**该模式的平台外解法是排版遮挡分工**

### 2. 类型视觉语法

- **科幻** ＝ 尺度对比（巨构 vs 人尺）＋ 冷基色 ＋ 单点暖 ＋ 大气透视
- **东方** ＝ 结构元素（飞檐斗拱）＋ 传统色（朱砂 / 鎏金 / 墨）

### 3. 融合策略须显式声明

以**东方结构为骨架、未来材质为皮肤**（全息灯笼、霓虹斗拱），或反之。**不声明则模型自行混合，风格纯度不可控。**

### 4. 叙事焦点单一化

**一个视觉锚点**（人尺角色或标志物）＋ **至多两条**次级线索；封面信息密度上限低于插画。
