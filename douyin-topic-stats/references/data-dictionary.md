# 数据字典与口径（选题统计技能）

## 1. 消费的字段（均来自作品列表接口，页面公开展示）

| 字段 | 来源 | 说明 |
|---|---|---|
| `video_id` / `video_url` | aweme_id | 构造跳转链接 `douyin.com/video/{id}` |
| `title` | desc | 标题/文案原文（含话题标签文本） |
| `hashtags` | text_extra | 话题标签数组，顺序即原标题顺序 |
| `likes` | statistics.digg_count | 点赞 |
| `comments` | statistics.comment_count | 评论数 |
| `favorites` | statistics.collect_count | 收藏 |
| `shares` | statistics.share_count | 转发 |
| `publish_time` | create_time | 发布时间（Unix 秒 → ISO），报告显示完整年月日 |
| `is_pinned` | is_top===1 | 置顶 |

**永不采集**：`statistics.play_count`（播放量）、`recommend_count`、`admire_count`、码率、播放/下载地址 —— 页面不展示，属非公开数据。

## 2. "最近 N 条"的含义

作品列表接口按**时间倒序**返回，`videoOrder` 的前 N 条即最新 N 条。
`--max-videos=N` 在滚动轮次后判断，由于每轮加载 18~20 条，**实采条数会略超 N**（100 → 约 110）。
生成报告时自动 `slice(0, N)` 截取，超出部分丢弃。这是预期行为，不是 bug。

## 3. 账号类型判定

判据是 `verification_type`：

| 值 | 含义 | 报告显示 |
|---|---|---|
| 2 | 企业认证（蓝V） | **企业号**（带蓝V徽章） |
| 1 | 个人认证（黄V） | 个人号 / 达人号（黄V个人认证） |
| 0 / 缺失 | 无认证 | 个人号 / 达人号 |

⚠️ 不要用"verification 非空"来判断企业号——实测会把黄V达人误判成企业号。
`enterprise_account` / 电商权限字段只作原始数据留档，不参与类型判定。
注：type=2 的语义来自抖音通用约定，采到真蓝V账号时建议用 `test/probe.js` 复核一次。

## 4. 选题聚类：两种模式

### 默认模式（零配置）
按每条视频**第一个真正的主题标签**聚类，自动跳过与账号昵称相同的标签（否则 #账号名 会把 90%+ 的条目归成一类，聚类失去意义）。
优点：通用于任何账号、无需配置。缺点：账号话题标签较泛时（如 #旅行 #vlog）粒度偏粗。

### 自定义模式（推荐，换账号时应定制）
传第三个参数指定规则文件（模板：`assets/topic-rules.example.json`）：

```json
{
  "clusters": [
    { "key": "系列A", "note": "说明", "pattern": "正则1|正则2" },
    { "key": "其他", "note": "兜底", "pattern": ".*" }
  ]
}
```

- **按优先级从上到下命中即归类**，最后一条务必用 `.*` 兜底
- `pattern` 是 JS 正则字符串，直接写中文字面量即可
- 正则里**不要写 `//` 空正则**（会被 JS 当行注释），兜底请用 `.*`
- 规则应来自实际标题样例：先跑一次默认模式，看完整清单里的标题句式，再写规则重跑

## 5. 排序功能

发布、点赞、评论、收藏、转发 5 列可点击排序。实现要点（供排障）：
表头必须放进显式 `<thead>` —— 若裸放 `<tr><th>` 在 `<table>` 下，浏览器会自动创建 tbody 把表头包进去，
导致 `querySelector('tbody')` 命中"只含表头"的那个 tbody，排序看起来没反应。

## 6. 常见问题

| 现象 | 处理 |
|---|---|
| 作品只采到首页 | 检查登录态（check-env 第 6 项）；访客态必被限流 |
| 实采条数 > N | 分页批次粒度导致，生成时自动截取，正常 |
| 聚类几乎全归一类 | 账号话题标签太泛 → 改用自定义规则文件 |
| 报告里没有"评论内容" | 本技能不采评论，需要评论洞察请用 douyin-benchmark-analysis |
| 采集时弹出验证码 | 立即停止，换时段再试；不并发、不多开 |
